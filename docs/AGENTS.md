# Docs — agent instructions

Instructions for agents working on files in this folder.

## Voice

All documents here are written in plain, direct wording. Do not apply brand voice. These are internal planning and process documents; brand voice is applied downstream in client-facing copy and content.

## Cross-referencing

When a document references another document by name or concept, link it using a relative markdown path — e.g. `[macro arc](./project-arc.md)`. Do not leave references as bare text.

## Footnotes

Use a `Footnotes` section for cross-document references that are helpful but not part of the main concept definition. Keep body sections focused on the document's own concept; use footnotes for "see also" pointers and artifact-location notes.

## CONTEXT.md

`CONTEXT.md` is a glossary of domain terms. Keep it devoid of implementation details, conventions, and decisions — those belong here or in ADRs. Only add a term when its meaning has been explicitly resolved and agreed.
