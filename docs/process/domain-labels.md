# Domain Labels

Every module, task, and deliverable in a project belongs to one of these domains.

- **Growth** — Surfaces and tooling that attract, convert, and retain users: the marketing site, analytics, email capture, and content.
- **Product** — The application itself: authentication, notifications, feature flags, error tracking, and any user-facing or revenue-generating functionality.
- **Infrastructure** — The platform the product runs on: hosting, deployment pipelines, and infrastructure health monitoring.
- **Tooling** — Internal-facing capabilities that support the team operating the product: admin panels, back-office workflows, and support tooling.
- **Planning** — Discovery, scoping, prioritisation, and coordination work that precedes or directs build work.
